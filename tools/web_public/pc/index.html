Start the bot on this PC

Open this page ON YOUR MAIN PC. Three steps, nothing to type. Disk full? Clean storage is further down. PC running hot, sleepy or slow? PC care (both work on both PCs).

1Make sure the Surface is off.

Start, Power, Shut down. Then NinjaTrader here: log in, connect MFFU, tick AT Interface.

2Download and double-click this. Download FRESH_START.bat

When it opens: if Windows says "protected your PC", click More info then Run anyway. Press Y to every question. It does everything by itself and never turns on real trading.

3In NinjaTrader press F5 once.

NinjaScript Editor, F5. Then LE START, Start trading. Text Claude "moved".

Clean storage (Surface and main PC)

Frees disk space: temp files, browser caches, Windows update leftovers, old logs. It first shows a table of what it would free and asks Y. It never touches the bot's data, your accounts, or NinjaTrader's charts and settings.

Download CLEAN_STORAGE.bat

Double-click it. If Windows says "protected your PC", click More info then Run anyway. Press Y. Windows asks once to make changes: click Yes. It takes a few minutes and ends with "Freed ... GB, C: now ... GB free".

If NinjaTrader or the bot is running it leaves their folders alone and only clears temp files, caches and Windows leftovers. The Recycle Bin and the old Windows copy (big) are asked about separately. Do it on both PCs.

Already have the bot folder? It is the same file: double-click CLEAN_STORAGE.bat there.

PC care (Surface and main PC)

One click to look after this PC. It finds out by itself which PC it is: the main PC (bot and NinjaTrader: never sleeps, high performance, screen off after 10 minutes) or the Surface (cooler, brighter screen, lighter). It shows a table of what it will change, asks Y, and ends with one line: BOT PC HEALTHY: YES or what needs you.

Download PC_CARE.bat

Double-click it. If Windows says "protected your PC", click More info then Run anyway. Windows asks once to make changes: click Yes. It also offers to switch off startup apps (Y or N for each), background apps and visual effects, and pauses Windows search indexing during market hours.

Nothing is closed, deleted or downloaded, and NinjaTrader and the bot are never touched. The CPU temperature is shown only if Windows lets a script read it; if not, it says so. To put everything back: double-click UNDO_PC_TUNE.bat (or run PC_CARE.bat again with -Undo).
