# OLYMPUS organization: four doors

Written 2026-11-18 (night-org). Owner: *"I can't find a lot of shit, so revamp if you need to and make it easy, whether it's Kalshi, Jarvis,
money or trading. I need everything organized, figure out a clean way."*

## The idea in one line

Everything sits behind **one of four doors**. Each door opens on the **5-8 things you use**, in plain words (the Greek app name is the small
line under it), then **"All apps in this door"**. One search finds everything by plain words: *payout, taxes, accounts, kalshi, brain, drawdown*.

The source of truth is one data file: `tools/web_public/olympus/doors.js` (copy: `web_next/js/next/doors.js`). Every one of the 75 apps
is in exactly one door (`tests.test_apps_list` part d). No app id or URL changed; only visible labels and grouping.
