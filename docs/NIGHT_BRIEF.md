- PAPER / SUGGESTIONS ONLY. Never place or arm real orders. Never touch `engine/`, `live_model*.json`, bot code, keys. Money tools only READ public data / published JSON and write a JSON file; they never trade. Free services only (no paid APIs). Network calls (if any) are stdlib, polite, timeout 10 s, optional, and every tool must work offline from a bundled fixture.
- DO NOT edit `tools/web_public/sw.js`, `tools/build_web_dashboard.py`, `tools/web_public/jarvis/apps.js`, the APPS table in `olympus/olympus.js`, `olympus/apps-list.js`. - Money-machine data contract: each scanner is `tools/money/<id>.py` (stdlib, `--out <dir>`, `--fixture` to use the bundled sample, `--selftest`) and writes `<dir>/<id>.json` = `{"v":1,"id":"<id>","asof":"ISO UTC","mode":"paper","status":"ok|stale|sample","headline":{"text":"plain sentence","usd_month":number|null},"items":[{"title","detail","usd":number|null,"score":0-100,"risk":"low|med|high","expires":"YYYY-MM-DD or ISO date, optional (a dated deal)"}],"notes":["plain caveats"]}`. Its page reads `../money/<id>.json` and falls back to its own `fixture.json`. Honest numbers only: label estimates "estimate", never promise income, show what could go wrong.
- Commit locally with a clear message. Final report to the lead: SIMPLE table (what / result), wiring needed, test commands, anything not done. Then wait: the lead may send more work.
