# Home Screen icon concepts (2026-10-17)

Black / purple neon app-icon concepts for the phone dashboard. Each SVG is 1024×1024, full bleed (iOS/Android apply the
mask), art inside the central r=400 safe zone. Not shipped yet: the owner picks one, then it is rendered to
`web/icons/*.png` (192, 512, maskable 512, apple-touch 180) and used by both dashboards.

1. `hud_lock.svg`: Target Lock HUD (reticle locked on the sweep point)
2. `event_horizon.svg`: Event Horizon (black hole; the polar jets are the candle's wicks)
3. `hex_core.svg`: Neon Hex Core (the current hexagon mark, rebuilt in neon)
4. `neon_tube.svg`: Neon Sign LE (the L's foot sweeps below a liquidity line)
5. `holo_chip.svg`: Holo AI Chip (iridescent chip with the candle at its core)
6. `synth_horizon.svg`: Synth Horizon (synthwave sun, grid floor, candle)
