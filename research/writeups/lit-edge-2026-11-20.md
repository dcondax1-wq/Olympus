## Method

- Base = the live LIT trades (tools/lit_edge `ctx()["T"]`, 631 trades, 120 in 2026). tools/research/litedge.py
  `manage_b` with every option off reproduces all 631 (`check`: 0 differ). Scoring = tools/lit_more_money.score
  (LIT size, eval path, funded Monte Carlo, week-block bootstrap, gate G1-G6).
- stale_sweep60 uses the engine's skip_keys and iterates (a freed day can bring a later stale setup too).
- es_room uses tools/lit_more_money.es_trade_for (ES stop 1 tick beyond ES's sweep-window extreme, ES VIX band target,
  ES 5m bars, MES $5 / pt sized to the same $ risk). ES data 2025-04-14 .. 2026-10-16.
- Limits fill only when price trades 1 tick through; the fill bar gets no target / breakeven credit.
- Fill map $ is an approximation: the trade's live result is kept for a filled limit plus the price gain; a missed
  fill is $0.
