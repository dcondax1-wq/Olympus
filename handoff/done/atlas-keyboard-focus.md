# Atlas favorites keyboard focus

The favorite button rerendered the entire card grid and removed its own focused DOM node. Keyboard users lost their position after one toggle. Atlas now restores focus to the replacement star, or to the Favorites filter when removing a card from that filtered list. A fallback catalog is visibly labeled limited if the generated app list fails to load, so four defaults do not appear to be the complete map.

`node --check atlas.js` passed. Rendered keyboard review waits for publication of Atlas to nq-dashboard.
